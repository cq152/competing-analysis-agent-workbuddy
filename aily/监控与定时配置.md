# 监控雷达 + 定时周报 配置说明（飞书 Aily）

> 这部分不是粘贴文本，而是要在 Aily 后台开启「工具 / MCP / 定时任务」能力。人设里已写好场景三（周报）和监控相关指令，这里讲怎么把"持续跟踪"接上。

## 一、监控雷达（P0 留存钩子）

**目标**：让 bot 留在群里——竞品一有动作，你比销售先知道。

**在 Aily 里这样配**：
1. 开启「联网」开关（竞品分析的命根子，必须开）。
2. 添加「飞书云文档」MCP（用于把监控/报告存为飞书文档并回链）。
3. 用「定时任务」能力做周期性巡检，或让用户在群里说 `加监控 竞品X` 触发添加。
4. 监控维度（变化检测，不是信息收集）：
   - 定价变动（官网价格页）
   - 功能上线（更新日志 / 公众号）
   - 融资 / 工商（天眼查）
   - 招聘信号（招聘页，反推战略）
   - 舆情 / 差评（小红书 / 抖音 / 黑猫 / 知乎）
5. 主动推送：检测到变化 → 推群，格式复用周报的「变化 + 为什么相关 + 建议」。
6. **相关度评分**：推送前按「和你业务的相关度」打分，只推高分项，避免噪声刷屏。
7. **免费层钩子**：1 个竞品永久免费监控（留存），超出按量 / 订阅收费。

> 初期先不接复杂 MCP；跑通对话和质量后再加监控与定时。

## 二、定时周报（P0 set-and-forget）

**配置示例**（在 Aily「定时任务」里建）：
- 触发：每周一 09:00
- 动作：调用场景三（竞品周报），汇总你指定赛道（如 AI 办公 / 协同 SaaS）的竞品动态，推送到本群
- 无重大变化时也发「本周无重大变化，保持关注 X」，避免群里以为 bot 挂了

## 三、验证顺序建议
1. 先粘 `人设.txt` + `开场白与推荐问题.txt`，在群里 @ 它跑通单轮对话（对照 `06-测试记录表.csv` 单场景项）。
2. 再开启联网 + 飞书云文档 MCP，测「存为飞书文档」。
3. 最后配监控 + 定时周报，测集成项（FS-01~04、MR-01）。
