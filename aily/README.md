# Aily 导入包（飞书可粘贴）

> 本目录是把已通过本地验证（`validation/`）的提示词，**打包成可直接粘进飞书 Aily 的成品**。
> 来源：人设 = `03` 系统提示词 + `05` 通用约束 + 4 个已验证场景；场景提示词与 `validation/prompts/*.txt` 完全一致。

## 文件清单

| 文件 | 粘贴到哪里 | 说明 |
|---|---|---|
| `人设.txt` | Aily 智能体「人设 / 指令」框 | **完整大脑**：角色 + 通用约束 + 4 场景（含触发/结构/红线/few-shot）。整段复制粘贴即可。 |
| `开场白与推荐问题.txt` | Aily「开场白」+「推荐问题」 | 降低首次使用门槛。 |
| `监控与定时配置.md` | 后台「工具/MCP/定时任务」 | 非粘贴文本，按说明开启联网、飞书云文档 MCP、定时周报。 |

## 导入步骤（约 15 分钟）

> 核对日期：2026-07-24，基于飞书官方文档。关键：直接进 aily 聊天界面没有配置项，必须先到「开发后台」。

1. 飞书客户端搜「飞书 aily」或浏览器开 aily.feishu.cn → 进 aily 页 → 左侧「前往开发后台」→ 进「飞书 aily 开发后台」。
2. 开发后台 →「新建智能体」→ 选「自定义智能体」。
3. 选「无感发布模式」（推荐，可边用边调人设）；若从 aily 专业版对话框「创建新版自定义智能体」进入则默认无感、无需选。
4. **粘人设**：把 `人设.txt` 整段复制进「角色设定 / 自定义角色设定与提示词」（在"技能"页）。
5. **开联网**：在能力 / 技能配置里开启「联网」开关——竞品分析的命根子。
6. **粘开场白**：把 `开场白与推荐问题.txt` 的内容粘进「开场欢迎语」+「推荐问题」（按 `---` 分隔为两部分）。
7. **喂知识库**（可选但推荐）：开发后台「知识空间」上传工作区 `01-市场研究报告.md` 等 5 个文件，让 Agent 带你的方法论和样例。
8. **加工具**：添加「飞书云文档」MCP（存报告用）。
9. **发群聊**：发布到飞书群，@ 它即可对话。
10. **配监控 + 定时**：按 `监控与定时配置.md` 开启监控雷达与周一 9:00 定时周报。

## 验证（进飞书后必做）

用 `06-测试记录表.csv`（26 项，4 个 P0 必测）逐条 @ 它验收：
- 单场景：BC / PR / WK / DC / MR
- 系统级：SYS-01~10（对应 `03` 验证清单）
- 对抗：AD-01~05
- 飞书集成：FS-01~04

**哪条不过** → 回 `validation/prompts/*.txt` 改对应红线 → 重跑 `run.py` 回归 → commit → 同步更新 `人设.txt`。

> ⚠️ 改提示词请以 `validation/prompts/*.txt` 为唯一入口（版本可控），不要只在飞书里手敲，否则会漂移。
