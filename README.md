## 1. 一句话定位

把竞品情报从「偶尔做的项目」变成「顺手的事」：竞品一有动作你比销售先知道；要应对话术、要定价参考、要周报，在飞书里 @一下就有。

**不是「战略分析师」，是「贴在飞书里的雷达 + 军师」** —— 便宜、即时、能直接用。

---

## 2. 目标用户与核心价值

- **目标用户**：中小企业（SMB）。不会养 CI 团队、不做季度竞品项目、没空读 30 页报告，但天天在飞书里、销售天天被竞品压价、老板天天焦虑对手又动了。
- **付费理由**：不为「战略报告」付钱，为「少丢一个单 / 少走一次弯路」付钱。
- **核心卖点**：省心、便宜、即时、能直接用（80 分速度 > 95 分深度）。

## 4. 产品功能

### P0（先跑通，且是留存命脉）
1. **竞品监控雷达**：加竞品 → 盯定价/功能/融资/招聘/舆情 → 变化主动推群（比单次分析重要十倍）。
2. **场景化问答**：内置场景模板（销售应对卡、定价参考、内容选题、市场进入），用户选场景而非填框架。
3. **红队 Battle Card**：「客户拿 X 压我们，怎么回？」生成一屏应对卡。最有感知价值。
4. **周报自动进群**：周一 9 点，3 条最相关变化 + 建议。set-and-forget。

### P1（差异化）
5. 上传即分析（截图/白皮书/官网，多模态）
6. 竞品发现（找出没意识到的间接/降维/跨界对手）
7. 中文互联网深掘（小红书/抖音/公众号/知乎/黑猫/天眼查/七麦）
8. 自家对标（我们 vs 竞品差距在哪）
9. 反向红队（如果我是竞品 X，会怎么打我们）

### 明确砍掉
30 页正式报告、自研爬虫集群、独立 Web 仪表盘、复杂 SSO —— SMB 用不上且拖慢、抬高成本。

## 5. 技术路线对比

| 维度 | 路线 A：飞书 Aily（当前） | 路线 B：自建 FastAPI（后续） |
|---|---|---|
| 形态 | 无代码/低代码智能体 | 全代码后端 + 飞书开放平台 Webhook |
| 速度 | 半天可在群里对话 | 2–4 周开发 |
| 富交互 | 受平台限制（卡片/对比矩阵做不到那么花） | 完整还原分析/对比/展开卡片、存为飞书文档 |
| 适用 | 验证体验与分析质量 | 验证完价值、要做成真产品时 |
| 详见 | `03-Aily智能体搭建指南与系统提示词.md` | `02-产品设计文档.md` |

**升级判定（满足任一即考虑走路线 B）**：卡片交互不够用 / 需要 Web 或自有 API / 需要实时外部触发 / 要对外收费。
